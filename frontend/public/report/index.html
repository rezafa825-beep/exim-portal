REZA SYSTEM

EXIM WhatsApp Report Generator

Baca file Excel secara lokal, pilih dokumen, atur jalur, lalu buat laporan siap salin ke WhatsApp.

1. Unggah file Excel CEISA

Belum ada file Excel yang ditambahkan.

Pilih banyak file sekaligus (tahan Ctrl atau Shift saat memilih). Anda juga bisa menambah file lagi kapan saja; file dengan isi yang sama dilewati otomatis. File diproses di browser ini; jangan unggah file Excel perusahaan ke repository GitHub.

2. Filter laporan

Default mengikuti hasil sistem: dokumen Keluar = Customer, dokumen Masuk = Supplier. Dropdown Customer/Supplier hanya mengubah keterangan pada laporan; pengambilan nama pihak dan filter tetap mengikuti pemetaan data otomatis yang sudah ada.

3. Pengaturan jalur

Semua dokumen HIJAU secara default. Centang nomor pendaftaran yang harus menjadi MERAH, atau ketik banyak nomor daftar pada kolom di bawah daftar.

Unggah Excel untuk menampilkan daftar dokumen.

Belum ada nomor daftar jalur merah manual.

4. Pengecualian nomor daftar

Centang nomor daftar yang tidak ingin dimasukkan ke laporan, atau ketik nomor secara manual. Pemilihan ini tidak menghapus data Excel.

Unggah Excel untuk menampilkan nomor daftar.

Belum ada nomor daftar yang dikecualikan.

5. Pilih dokumen untuk Copy Data Excel / Export Excel

Daftar mengikuti filter jenis dokumen, Customer/Supplier, dan pengecualian nomor daftar. Centang dokumen yang ingin dimasukkan ke laporan Excel.

Unggah Excel untuk menampilkan dokumen.

0 dokumen dipilih untuk ekspor.

6. Pratinjau laporan WhatsApp

7. Copy Data Excel / Export Excel

Fitur terpisah dari laporan WhatsApp. Menggunakan dokumen yang dicentang pada bagian 5 dan mengikuti filter yang sedang aktif.

Pilih dokumen pada bagian 5 untuk mengaktifkan fitur ini.

8. Tracking BC 4.0

Output tambahan untuk template tracking. Menggunakan dokumen BC 4.0 yang dicentang pada bagian 5. Satu nomor AJU menjadi satu baris. Tanggal Masuk diambil dari Tanggal Daftar CEISA.

Pilih jenis dokumen BC 4.0 dan centang dokumen pada bagian 5 untuk menampilkan data tracking.
